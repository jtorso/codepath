# 🍕 College Cooking — Tortilla Pizza Event

**College Cooking** is a front-end web project built using **HTML, CSS, and JavaScript** that promotes a fun, budget-friendly cooking event for college students. The site highlights a hands-on **Tortilla Pizza Workshop**, complete with an event schedule, interactive RSVP form, and responsive design — perfect for learning and showcasing front-end fundamentals.

---

## 🌐 Live Demo
[👉 https://codepath-seven.vercel.app/](#)  

---

## 💡 Features

- **Responsive Design:** Built with pure HTML/CSS to adapt smoothly across screen sizes.  
- **Dark/Light Theme Toggle:** Saves preference in `localStorage` for seamless user experience.  
- **Interactive RSVP Form:**  
  - Validates inputs for name, campus, and email.  
  - Displays successful signups dynamically without page reloads.  
  - Includes real-time inline error messages and reset functionality.  
- **Event Schedule Cards:** Visually engaging layout for the cooking event timeline.  
- **Embedded YouTube Video:** Clean, responsive video integration for live demos.  
- **Accessibility & ARIA Support:** Semantic tags and roles for inclusive design.  
- **Modern UI Elements:** Cards, gradients, chips, and smooth hover effects.
